Safety notes

• Duplicate check uses type + local date + hour + minute, so repeated imports should not double your history.
• Imported entries become type One, marked as backdated, with standard volume only when volume data says “standard/normal/medium”.
• If anything looks wrong, use the backup JSON downloaded before importing.
